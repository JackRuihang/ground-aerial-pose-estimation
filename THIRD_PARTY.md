# External components in the broader thesis

This solver-only release contains no MicKey, DINOv2, DUSt3R, MASt3R or CroCo code.
PyTorch is an external runtime dependency installed from its original distribution.

For the original image-matching work, consult the original projects and licenses:
- https://github.com/nianticlabs/mickey
- https://github.com/facebookresearch/dinov2
- https://github.com/naver/dust3r
- https://github.com/naver/mast3r
- https://github.com/naver/croco

MicKey's custom license restricts redistribution; its bundled local modifications are
not included. This release is independently testable without those components.
